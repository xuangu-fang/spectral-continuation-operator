# 从独立频率包络到共同传播生成器：有条件POC

> 2026-10-03；开发假设，不是已完成结果。不改变原始主指标和两域gate。

## 为什么值得做这一项

当前512训练环境的直接包络FNO最佳误差0.175，核回归0.162；增加数据有效，但没有神经优势。
另一方面，同一波导的已知完整介质可以编码成少量实对称质量矩阵，64单元经典传播误差约0.00065。
这提示一种尚未验证的替代：不让每个频率预测独立复包络，而让它们共享产生响应的实算子。

最简单的连续生成式（这里不是概率生成模型）为：

$$
\frac{d a}{d r}=\left(i\sqrt{\omega^2 M(r)-D}-\alpha I\right)a.
$$

其中a是复模态向量；M来自声速，实对称正定；D是已知深度导数矩阵。频率通过明确的平方律进入，
振荡由矩阵传播产生，不由固定图像分辨率承担。一个M能回答多个频率和源查询。

这只是现有单向波导的物理结构，**不是新方程、新求解器或已完成的神经方法**。完整Helmholtz、
海底穿透和反射尚不包含。生成器表示/系统识别已有丰富文献，不能仅换名称声明创新。

## 信息协议不暗改

- 输入仍是60/100/140Hz三个完整复场、已知静态背景、边界与源相位约定；不输入完整距离相关SSP。
- 目标为零该频率观测的70/80/90/110/120/130Hz完整复场；原8开发环境保持不变。
- 先分别检查65个压缩剖面和完整2049观测剖面的编码误差，额外处理/存储费用必须报告。
- 仿真真实M或声速只作为容量oracle或训练监督标签，不能进入开发实例编码输入。
- 已知完整SSP的经典求解器继续保留为额外信息上限；同信息必须比较context-only经典反演。

## 先诊断，再学习

1. **局部经典识别控制。** 对已观测场求模态导数，估计频率无关的慢度平方扰动；使用实低维深度
   基和正则最小二乘。单向模型转成二阶方程会遗漏生成器的空间导数项，明确只是近似，先量化偏差。
2. **表示oracle。** 把真实慢度平方投影到相同深度基，查询未见频率，确认精度余量不是假设。
3. **共享学习仅在前两项之后启动。** 可学习局部编码/识别偏差修正或算子坐标，不直接枚举更大
   FNO。对照同数据监督的线性/核回归及无监督context拟合；所有真值标签成本明确。
4. 候选若达到开发raw≤0.10且比最强同信息基线改善≥20%，才增加非整数频率、三seed、源变化、
   独立坐标和第二域。候选不通过则记录识别/偏差/编码瓶颈，不重复宽度扫描。

本项的潜在科学增量是检验“学习跨查询共享的物理生成规律”是否比“学习已压缩的场值曲线”更可预测。
只有实证才决定能否成为AI贡献；如果经典识别就解决任务，它是强基线和有用事实，不强行加入网络。
