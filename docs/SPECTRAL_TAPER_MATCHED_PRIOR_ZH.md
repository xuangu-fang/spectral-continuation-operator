# 谱尺度变化失败后的“已知新分布”救援对照：运行前协议

> 2026-10-04约10:00 UTC，在固定旧谱先验的taper10新16环境负结果和目标泄漏oracle设计之后登记。原16系统已经被看过，因此这只是**事后机制对照**，不能被写成新的独立确认或分布外方法成绩。与目标响应oracle不同，此方法测试时仍只读60/100/140Hz低频复场，但训练期额外得到目标统计族的介质标签。

## 要区分什么

旧taper5介质训练出的rank256先验在taper10环境800Hz raw约0.416/0.435；真实介质32项物理oracle约0.003。问题可能是该新介质族本身很难从低频辨识，也可能主要是旧训练先验不覆盖新的细尺度。这里用**全新且不与测试16系统重叠**的512个taper10介质标签重拟合相同rank256 PCA先验，保持同一低频输入、同一已知方程/源、同一5+5GN和800Hz双源完整指标。若准确率恢复，说明“新族难”不是唯一解释；若不恢复，再看读取真介质的新PCA投影oracle区分容量与识别。

训练seed20266000–20266511，原测试seed20267000–015。介质仍16×16余弦速度系数、RMS15m/s、taper10；只训练在64距离段×32垂向项的介质标签，不读高频目标场。方法维数仍256，背景、源、context三频×65条、400/800Hz双源完整ROI和数值真值复用原OOD协议；不重调先验精度、GN步数或ROI。非部署oracle是读取真测试介质的**新匹配PCA欧氏投影**，不混入主方法比较。

事后探索门槛：800Hz双源的匹配先验低频部署raw和相位均≤0.05，且raw相对旧taper5先验同16系统至少降低70%；400Hz、最差系统和全部失败如实报告。**通过不表示旧方法跨taper泛化**，只表示提供新分布介质标签后可重训救援；不能把新标签成本隐去。无论结果如何不再对这批系统继续扫描rank/超参。配置：[JSON](../configs/coherent_waveguide_spectral_taper_matched_prior_20261004.json)；实现`src/spectral_continuation/audit_waveguide_spectral_taper_matched_prior.py`；代码/协议先提交再运行。

## 完成结果：重训有大幅收益，但未恢复高精度

额外512个目标taper10训练介质标签已生成，SHA及种子保存在同名artifact；16个已用OOD系统完整评价128行。800Hz宽/窄源，固定旧taper5先验的部署raw为0.41554/0.43498；新匹配先验、同低频context及同5+5GN后的raw为**0.12705/0.13668**，相位**0.10172/0.10970rad**，最差系统raw0.20052/0.25379。raw降幅分别69.43%/68.58%，差一点点但确实**未达到**预设各≥70%，双源raw/相位≤0.05门槛也全部失败。400Hz宽/窄raw为0.05503/0.05930，也未全到0.05。

额外读取真实测试介质、在**新匹配PCA256空间**作欧氏投影的800Hz宽/窄raw仍**0.06728/0.06516**，相位0.05135/0.04981rad，远高于真实32项物理oracle约0.0028；它不是响应最优代码。目标taper10训练标签前256个PCA方向虽解释约**99.99675%**的介质系数方差，残余细尺度方向仍足以影响相干响应，延续了“高方差覆盖≠相位精度”的主要科学发现。新先验低频context最后一步归一化平方残差平均3.56×10⁻⁶，比旧taper5先验2.93×10⁻⁵低约8.2倍，但仍高于同分布taper5确认集约4.66×10⁻⁸；三组不是配对环境，比例只作诊断。

因此“旧先验与新统计不匹配”确实解释相当一部分失败，却**不是唯一原因**：即使额外给目标统计族512介质标签、仍保持256维，低频部署也未恢复0.05精度。当前证据不能区分更高维代码、非线性/响应感知表征或更好低频反演各可贡献多少；按运行前约定不继续对这批已看过系统扫rank/超参。此结果绝不是旧方法的分布外泛化成功，更不是新AI方法。
