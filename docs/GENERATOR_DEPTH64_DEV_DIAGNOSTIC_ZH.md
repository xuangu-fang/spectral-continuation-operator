# 更高频下增加生成器垂向带宽：单一开发诊断

> 2026-10-04在查看新32独立系统结果前记录。仅使用旧8开发环境，目标仍是高精度复相位。

现有频率曲线在800Hz显示：32深度项真实介质oracle，宽/窄源raw约0.00135/0.00215；
64深度项真实介质oracle降为约0.000124/0.000213。当前32项、128维推断代码约0.00351/
0.00356。差距为具体的表示带宽/推断机制线索，值得仅试一次“深度64项、相同128实代码”。

训练先验仍用原512训练介质标签，拟合64距离中心×64深度余弦项的rank128 PCA。环境代码维数
仍128；全局basis和训练标签变大，不宣称免费增精度。新先验初值只由旧8系统的32项context推断
值投影得到，不接触800Hz真值。然后读出到256段，同60/100/140Hz、65剖面再做固定5次全程GN；
预测时用128模态、384点积分，不按高频结果挑停止步。比较已经完成的32项代码、真介质32/64
oracle、完整介质oracle；140/400/800Hz全报告宽/窄两源与幅值/相位。

预期任何收益都先归给**线性统计先验的更高物理带宽**，不能算作新深神经方法。若更高带宽
不改善，检查容量投影oracle与context条件，停止进一步扫深度项/rank/step；若明显改善，也只
提出表示学习的机制问题，独立32新系统已经用于确认先前的32项版本，不能事后把64项回写成
它的预注册候选。真实SSP投影oracle继续作为额外信息诊断，不与部署方法混表。
