## 大白话：图片看起来很像，为什么代入波动方程会出问题？

波动方程不仅看某点的场值，还看它附近怎样变化——尤其是二阶空间导数，可以理解成局部弯曲程度。
一个很小、很密的锯齿，视觉上不明显，却可能有很大的二阶导数。因此“在采样点把复场预测准”，
与“得到一个能在更细坐标上稳定求导的连续场”，不是同一个保证。

最简单的例子是误差 `epsilon * sin(k*x)`：误差幅值只有epsilon，但二阶导数的幅值是
`epsilon*k^2`。这里没有新的信号处理定理；它说明为什么高频表示必须比普通图片重建更关心平滑性
和求导误差，也说明不能将PDE残差和场值误差不加条件地等同。

## 本轮真正观察到了什么

已知介质/源/PDE，给定6/10/14三个完整频率场，回答非整数频率；目标频率没有场观测。
先在257-grid编码，再直接在513-grid求值，目标来自独立求解器。

对于纯传播相位基：

- 保持原来的少数复系数，细网格场值误差约0.029；
- 同一批基函数，用细网格波动方程重新决定系数，反而变成约0.388；
- 用目标真值去拟合系数，最优约0.020；这只是oracle，不能部署。

所以不是这个基空间完全装不下正确场，而是它在更细离散下的物理作用不稳定。保持粗网格系数时，
PDE相对残差约1.20，约99.91%的平方残差在源附近。这个百分比是当前两个环境、三个频率的均值，
不是任意波场的一般事实。

## 为什么出问题：把不适用于源附近的载波当成处处适用

我们使用“沿传播路径的走时”作为相位，均匀介质时类似`exp(i*k*r)`，r是到源的距离。
距离在源点有尖点；但有限宽度Gaussian声源的实际场没有同样的尖点。

数学上仍可把真实场写成“这个载波×某个包络”，可是包络必须包含一个反向尖点，才能精确抵消。
这与“包络处处平滑、可以独立插值”的建模假设冲突。分开插值之后，两项不再精确抵消，二阶导数
就出现假的强源项。

仅用已知源宽度对载波平滑，不增加列数，细网格物理投影恢复到约0.029；保留实际有限源复响应，
配合同样的平滑处理，则约0.020。这是成对干预支持的归因。改善属于经典数值/物理修正，不能标成
神经模型相对经典方法的巨大提升。

## 对AI表征的要求，而不是另加一串loss

一个候选方向是**可参与算子计算的连续相干表示**：不仅支持“查询场值”，还支持“在新分辨率上施加
物理算子”。这要求编码、潜变量和解码器的设计一致。

1. 快速振荡尽量由明确的传播结构生成，不让隐变量逐像素记条纹。
2. 不同物理区域允许不同载波：有限源邻域、传播区、界面/焦散区未必适合同一渐近公式。
3. 包络及网络输入本身也必须满足所需的光滑性。只把最终指数项变光滑，而让网络读取未平滑的
   `x/r`、`r`，仍可能重新引入尖点。
4. 分开评价场值精度、物理作用精度与跨网格稳定性。主指标仍是原始复场误差，不替换成更好看的残差。

本轮正在做的最小迭代只处理有限源：同时平滑相位、径向包络因子和神经输入；保持网络参数数、
基函数列数和唯一的复场训练损失不变。与采用同样修正的固定基、两参数基比较；未证明≥20%学习
优势之前，不进入“新AI框架已成功”的叙事。

## 哪些是已有知识，哪些是当前增量

| 内容 | 归属 |
|---|---|
| 小场值误差不保证小导数误差；渐近波相位在源附近需特殊处理 | 传统分析/数值波动理论 |
| 相位预处理与基空间降阶、神经基空间、输入输出算子一致性 | 已有研究，见POC文档文献表 |
| 同一开发任务中：值误差约0.029但细网格重投影约0.388，以及源附近残差定位 | 当前实验事实 |
| 不增加基规模的平滑修正恢复约0.029，真实源复参考约0.020 | 当前数据上的经典机制验证 |
| 这种约束能形成跨介质/频率/维数可泛化的优秀学习表示 | 尚待证明的研究假设 |

这一线有科学价值，但目前不能据此宣称已经有一篇顶会方法论文。下一步应证明学习负责的结构在
复杂传播中不可被更简单的经典对照同样高效地替代，并保留Ocean模态出现等不同失效机制，避免将
一个源点诊断强行包装成所有波场问题的解释。
