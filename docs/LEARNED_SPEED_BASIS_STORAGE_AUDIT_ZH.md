# 学得声速基的存储审计：低秩分离而不改方法

速度PCA255在64×160网格上有约262万个float64，共享基存储是同255码慢度平方PCA的5倍。开发成绩不能掩盖成本差异。本审计在**已经固定的**声速基上做一次数据导出的深度方向SVD，只问能否在不改变任何预测的条件下把共享基写成“距离×深度基×代码”的函数张量形式；不重训、不用新环境或目标频率真值、不给方法增加额外先验。实施前配置见[JSON](../configs/coherent_waveguide_speed_basis_storage_audit_20261004.json)。

设已训练的速度增量表示为`mean[r,z] + sum_k factor[r,z,k]*a[k]`。把所有`r,k`的深度曲线与均值一起组成矩阵，做SVD取前16条**从数据学得的深度基**`B[z,j]`，保存`A[r,j,k]`、均值坐标`m[r,j]`与`B[z,j]`。在线调用时先恢复速度，再走完全相同的`c^{-2}`映射与传播物理。合成数据恰是16个深度余弦模态，所以rank16可能几乎无损；这不是对真实海洋/3D波场的低秩保证，更不是新神经网络。

运行后必须报告：整个冻结先验的相对/最大重建误差、一个**预选已用开发系统20267000**固定代码在256距离段的beta差异、float64数量及压缩率。预设门槛为前两种相对误差各≤1e-10。若失败，不能再根据结果扩大rank宣称无损；此审计只服务于公平存储说明，不会重算或更改新taper7.5确认的冻结模型。

## 结果

协议与代码提交`8d5cd0c`后运行。冻结共享基深度奇异值第16条约100.86，第17条仅5.88e-12；这**源于合成器只有16个余弦深度分量**。数据驱动rank16分解后，完整均值与系数基相对误差**2.56e-15**、最大绝对差2.74e-13；预选旧开发系统固定坐标在256距离段的生成器beta相对差**3.91e-15**、最大绝对差6.42e-17，两项预设无损门槛通过。

| 共享基表示 | float64数值个数 | 相对原始速度基 |
|---|---:|---:|
| 原始64×160×255声速基＋均值 | 2,621,440 | 1.000 |
| 数据学得16条深度基＋64×16×255核心＋均值核心 | **264,704** | **0.101** |
| 同代码维数的64×32×255慢度平方PCA＋均值 | 524,288 | 0.200 |

因此**磁盘/共享参数数值个数**可从“速度基为q的5倍”变成“压缩速度基约为q的0.505倍”，同时数学上基本不改解码值。这不是**在线推断时间**改善：当前运行仍先展开到高密度网格，未实现核心张量直接收缩/压缩Jacobian计算。大NPZ `compressed_speed_prior.npz`仅在本机artifact，Git保存配置、SHA和[summary](../artifacts/coherent_waveguide_speed_basis_storage_audit_20261004/summary.json)。换成不同介质族、3D、强局部缺陷或非分离结构时，rank16会不会有效尚未验证；也不能因为这个存储审计把PCA改名成新的深度神经方法。
