# A · 测几个位置，把相位场补准

## 一句话与一个公式

**在一个新环境里，同一个声源、同一个频率，只测少量位置，重建其他位置的复数波场。**

```text
{位置 xi, 复测量 ui} + 查询位置 x → 预测复场 u(x)
```

频率、声源和坐标单位已知；绝对相位默认有共同参考。
我们首先解决“这一张场没测全”，不是“完全没测这个频率，还要猜出它”。

## 真实用途与新意边界

海洋阵列、超声扫描、空间声学都不容易密集布设传感器。
比得到好看的幅值图更重要的是：重构结果能否保留传感器之间的相位关系，支持相干叠加或后续反演。

这是已有的稀疏重构问题，HarmoCore 也已研究过。可争取的新贡献不是任务命名，而是：

> **学一个由稀疏测量容易确定、对相位误差敏感的连续表示，让同样的传感器获得更准的复场。**

“容易确定”是指不同候选表示不能在观测处几乎一样、在查询处却差很多。
它不是要求表示越小越好。

## 最小方法假设

先做“共享学习表示 + 简单观测拟合 + 坐标读出”。模型可离线学习跨环境的规律，
到新环境时只根据测量估计小量隐变量；也可用集合 encoder 初始化，但先不必同时加两套机制。

关键对比是：同样的观测拟合器，普通复数表示与相位敏感表示是否不同。
可以用训练集支持的传播背景组织复数基，或按查询误差而非像素压缩误差学习表示；
不能偷用真实测试声速、路径、完整目标场来定义这些基。

旧的 episodic basis learning 已试过，Deepwave 无提升、OpenFWI 约 1.4%。
因此“把 PCA 换成可训练 basis”本身不是新假设；应明确新的表示结构或传感器条件，并做单变量对照。
不要求先上 diffusion，也不把全部问题退化为输出低秩系数。

## 数据怎么用

- **首选 Ocean 完整复场**：从同一频率切稀疏观测与未测查询；现有合成数据可直接重划 observation mask，
  但已有系统已用过，只能诚实标记 DEV。
- **公开第二域 WaveBench**：完整复场和声速标签可用；主模型不能暗中用标签。
  先固定一个频率重构，再跨其现有四频测试。没有连续频率真值，不凭插值声称连续谱泛化。
- **可控 Helmholtz**：适合诊断物理先验，但现有 multiscale 只有 8 个 DEV 响应系统，
  512 份训练介质不是 512 份训练场。需要时生成足够响应，先审计经典逆解。
- Deepwave/OpenFWI 现成文件主要是接收阵列，能做阵列补全，不能当成全内部场真值。

已有 Helmholtz 四线三频切片属于跨频任务，不直接等于本路线。[完整数据边界](../../data/README.md)。

## 潜在基线及当前实现状态

| 基线 | 为什么要比 | 本仓库状态 |
|---|---|---|
| 复数插值、固定基 + ridge/MAP | 识别“其实平滑插值已足够” | 有相关实现，需适配同频稀疏切分 |
| PCA/函数张量基 + 观测拟合 | 对照学习表示是否真有用 | 有历史组件，不等于 A 已评测 |
| 坐标网络、set encoder + 连续 decoder | 普通学习重构对照 | 有旧 neural-field 组件；新协议需适配 |
| HarmoCore | 同类任务、用户已有工作 | 本仓库不宣称已有公平复现；需定位作者实现与匹配预算 |
| 已知 PDE 的正则化逆解 | 防止学习只胜过弱基线 | 有波导/Helmholtz 诊断；稀疏同频版本需验证 |
| FNO/DeepONet 类模型 | 算子学习对照 | 需恰当的稀疏输入适配，不称其已有新协议成绩 |

已知真实介质的求解器只作 extra-information 上界，不是同信息量基线。

## 第一阶段怎样算有进展

先固定两个域、三档合理绝对传感器数和一个布点方式；绝对数与占总网格比例都报告。
主表只统计未测位置的 raw complex RelL2、能量加权圆周相位误差，同时保留幅值误差和尾部系统。
之后才检验换布点、噪声、较高频率；不一开始要求所有泛化轴。

开发候选至少要在强基线之上产生实质且稳定的复场/相位收益，才申请独立确认；
预建议门槛见[统一协议](EVALUATION_ZH.md)，不是已达成绩或投稿承诺。

**停止信号：**只在观测点变准、只靠全局相位对齐后变准、或只胜弱插值；
参数变多却无跨系统收益；误差已接近数值真值误差还继续刷百分比。

连续谱是后续可选查询轴，不是首阶段任务。
