# 三条路线共用的评价底线

> 这是下一阶段协议模板，不是已经冻结的新实验 gate，也不是承诺某个百分比就能发论文。

## 一、先锁定信息条件，再选模型

每份实验配置写清：环境是否未见、source/frequency、观测坐标与预算、噪声、相位参考、
可用背景/PDE/介质标签、目标坐标和数值真值精度。
训练可用介质标签也属于监督成本，不能隐去。
所有归一化、PCA、神经网络、memory、超参数只从 train/validation 得到。

A 的目标位置不能出现在输入；B 的目标声源不在示范；C 的高保真目标不进入校准。
坐标附近强相关的随机 mask 与整段/整区域留出是不同难度，应分别命名。
不要用不同物理系统、不同点数、不同 source 预算间的百分比排名方法。

## 二、复场和相位一起看

主指标始终在**未测位置**计算：

```text
raw complex RelL2 = ||预测复场 - 真复场||2 / ||真复场||2
相位差 = angle(预测复场 × 真复场的共轭)，取值在 [-π, π]
圆周相位误差 = 按真场能量加权的 |相位差| 均值
```

幅值相对 L2 同时报告。只在验证时固定的有效信号阈值以上统计相位，报告保留能量/点数比例；
主 raw complex 指标不借此丢弃困难点。预测为零而真值显著的点不能通过预测幅值阈值被排除，
须明确零预测的相位处理并保留 raw 惩罚。改变权重/阈值要同时给敏感性检查。

不用普通未加权 phase MAE 让零幅值处的无意义角度主导结论。
不将 cosine phase loss、coherence、角度 MAE 混成同一个量。
不在主指标中事后旋转预测场以对齐真值；相位对齐后的分数可作诊断，另列。
若真实设备没有共同相位参考，先定义相对相位/时钟校准任务，不能声称恢复不可观测的绝对相位。

逐系统报告均值、中位数、较差分位数和配对置信区间；一个环境的多个频率/源/随机 mask
先在系统内汇总，不把它们当独立样本。跨域分别列指标，不把不同物理难度平均掩盖。
生成方法以后若使用，要报后验校准及单次/均值风险，不拿 best-of-K oracle 当部署成绩。

## 三、建议的开发晋级条件

先由实际用途和数值真值确定可接受绝对误差，再冻结门槛。
可用的首轮筛选建议是：两个域、每域三档预算中至少两档，
raw complex 与相位误差相对**验证集选定的最强同信息基线**均改善约 20%，
没有明显尾部恶化；在可承受成本下重复学习种子与 prompt 随机种子。
这是投入更多确认实验的标准，不是保证成功、更不是为了达标修改已见测试口径。

即使相对改善达标，若 raw 仍约 0.5，则不能称高精度。
raw ≤ 0.05 可作部分受控仿真的候选精度目标，**不是跨所有波场和应用的通用门槛**；
0.95 → 0.88 也不能只因为相位某个指标好看就升级为成功。

相反，若已有强物理基线 raw 约 1e-4，接近求解器误差，任务可能没有值得学习的精度空间。
不要主动削弱基线制造百分比收益；可以检验实际存在的观测稀疏、模型偏差或计算预算约束，
但这属于另一个明确记录的信息条件。

## 四、公平成本与可复现性

- 参数、shared basis / memory 存储、离线标签/训练成本、在线拟合和物理求解均记录。
- 神经网络免微调与每实例隐变量优化/微调分栏；不要用 ICL 省略在线计算。
- 所有采样密度变化优先直接求解新坐标真值；图像插值不是独立高分辨率标签。
- `test` 名称不保证从未看过。已用于方法选择的批次改作 DEV，不能重新封成独立 test。
- 留存原 gate、失败配置与预测摘要；新假设另建配置与输出目录，不覆盖历史。
- C 配对必须追踪独立求解来源；B 需查 source/receiver 共址与互易性，避免目标泄漏。
- 冻结评价后只读确认一次；失败诚实记录，不挪动指标到容易成功的位置。
