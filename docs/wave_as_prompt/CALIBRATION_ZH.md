# C · 用少量测量，把近似模拟校准

## 一句话与一个公式

**已有一个能运行、但与真实环境有偏差的模型，用少量可信测量校正它，再预测未测响应。**

```text
近似模型 u0 + {位置/实验 qi, 真实测量 yi} + 查询 q → 校准响应 u(q)
```

第一阶段先校准同频的未测空间/接收位置。不将跨频远距离延拓设为必要条件。
“真实测量”在合成 POC 中指独立高保真模拟输出，必须明确标为 synthetic，不冒称海试。

## 真实需求与新意

实际海洋中知道大致声速和几何，仍可能有声速偏差、边界误差或不同求解器的模型差异。
目标不是让 AI 从零替代全部物理，而是**学习可迁移的错误结构，让少量观测足以校正当前模型**。

模型校正、多保真学习和数据同化不是新任务。
可以争取的贡献是：相较直接拟合误差图，学习更易由观测确定、又对相位有效的修正表示；
在新环境和未见偏差强度上仍有收益。

## 最小方法假设

先选一种物理上合理的偏差，例如声速剖面的测量平滑/偏置。
模型学习这类偏差如何影响响应，在线只确定当前环境的小量修正。
误差图 residual 是重要对照；修正传播参数或相位积累是可检验候选，而不是预定优胜者。

如果简单的物理参数校准已经接近数值精度，就没有理由添加复杂网络。
如果一个传感器布局无法区分多种修正，也不能指望 flow 自动增加观测信息。

## 什么数据才算够

需要同一系统 ID、同一 source/frequency/coordinates 下两套**独立计算**的输出：

- 近似模型：来自明确偏差的环境或便宜求解器。
- 高保真模型：作为 synthetic 观测和查询真值。
- 校准位置与查询位置分开；偏差机制、计算成本、相位约定有记录。
- 训练、开发、确认按物理系统划分；不得把高保真隐藏参数留在可读取的 prompt metadata。

现有海洋求解器可支持生成，但**没有成熟的大规模 C 配对训练集**。
旧的 Pekeris 8 模态/全模态 pilot 只有 3 个环境，是诊断资源，不是训练基准。
OpenFWI 当前本机介质不匹配，不能凭它构造可信的近似环境；
Deepwave、structural lattice 可以受控再生成，但本轮没有生成。

## 旧经验如何帮助设计

旧同一高保真库内稀疏谱校准，raw 约 0.4106 → 0.3611，有约 12% 的近带收益，
真实配对胜过打乱配对，说明测量包含当前实例信息。
**它不是独立 LF/HF 实验，也不是高精度重构。**

真正独立的 8 模态/全模态 pilot 中，受限 AR 校准在验证环境 raw 约 0.7057 → 0.5950，
平均改善约 15.7%，远频端甚至恶化。说明那种近似和修正族不适合当时的远频目标，
不能推导所有校准方法都不可行。

因此不重启旧的固定 8 模态远频任务，也不以最难的跨频错配起步。
[原始负结果](../../reports/PAIRED_FIDELITY_CALIBRATION_GATE_ZH.md)保留，早期“信息上限”表述不作为现行结论。

## 潜在基线

| 基线 | 意义 | 当前状态 |
|---|---|---|
| 不校准的近似模拟 | 必须优于的起点 | 求解器可用 |
| 直接复数 residual 插值 / ridge / GP | 判断平滑误差修补是否已足够 | 有旧校准/统计组件；新任务需适配 |
| 少量物理参数的正则化校准 | 同信息量强对照 | 有逆解组件；具体偏差协议未建立 |
| 学习误差图 / 学习算子修正 | AI 方法对照 | 新协议待实现；不可宣称已有成绩 |
| A 的不使用近似模型版本 | 检查模拟到底是否帮助 | A 新协议建立后做共享消融 |
| 真实高保真介质求解 | 数值上限/额外信息对照 | 不放入同信息量排名 |

## 推进与停止

先检验配对数据的相位参考、成本和真值收敛；再看一个物理校准和一个简单 residual。
有稳定 headroom 才学习修正结构。
与 C 同时比较 A 时必须给相同测量、同样训练监督并明确 C 额外拥有近似模型。

如果只是给高保真标签加平滑噪声制造优势，或低保真模拟并不更便宜也不代表现实不确定性，
就停止并重新检查需求。若 raw 改善但相位恶化，不能叫相位校准成功。
