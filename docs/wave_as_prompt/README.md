# Wave as Prompt：三张问题卡

> 2026-10-05；当前研究边界。这里只定义任务与待检验假设，不把旧成绩改名成新结果。

| 问题卡 | 给模型什么 | 要它回答什么 | 首选已有资产 |
|---|---|---|---|
| [A：补全波场](RECONSTRUCTION_ZH.md) | 同源同频的少量复测量 | 其余位置的复场/相位 | Ocean 完整复场、WaveBench |
| [B：预测新实验](NEW_EXPERIMENT_ZH.md) | 同环境几个声源的响应 | 新声源的响应 | Deepwave、OpenFWI、Ocean 多源 |
| [C：校准模拟](CALIBRATION_ZH.md) | 近似模拟 + 少量可信测量 | 修正后的未测响应 | 海洋求解器；旧配对 pilot 仅作诊断 |

共同形式：

```text
预测响应 = 模型(测量集合, 查询, 可选近似模型)
```

“集合”意味着传感器数量和位置可以变，不要求输入永远是一张固定网格图片。
但可变输入不自动等于泛化成功；必须在未见环境和预先规定的布点变化上测试。

## 只设三个共同接口，不先规定一套巨型模型

- 输入：复测量、坐标、声源/频率与相位参考；真实可用的背景信息必须声明。
- 输出：查询位置/实验的复数响应；幅值与相位由该响应计算。
- 评价：同信息量、未测目标、逐系统统计；学习参数与每实例拟合分开报告。

技术上可共享 encoder、连续坐标读出、训练 episode 和物理算子；**没有要求三条路线共用同一个训练模型**。
`research_catalog.json` 是可检索的资产目录，不是模型可直接读取的数据 manifest。
