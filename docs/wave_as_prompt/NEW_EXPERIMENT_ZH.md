# B · 看几次实验，预测换一个声源会怎样

## 一句话与一个公式

**在没见过的环境里，给模型几个声源的响应示范，让它预测另一个声源的响应。**

```text
{声源 si → 接收响应 yi} + 新声源 s* + 查询接收位置 r → y(s*, r)
```

第一阶段频率相同。目标声源不出现在 prompt 中；测试环境不参与训练。
给几个完整接收阵列的示范，与给几个孤立测量不是同一预算，必须分别计数。

## 需求与贡献边界

在海洋探测、超声阵列和地震勘探中，收集每个激励下的响应都需要成本。
目标是“测过部分实验后少做一些实验”，而不是简单填补一张图。

少样本声学预测和 in-context operator learning 已有先例。
我们可争取的是**能从少量实验识别相干响应规律、支持新激励的学习表示**，
而不是发明了 demonstrations 或给普通网络换一个 Prompt 名称。

## 最小方法假设

示范共同描述同一个环境。将它们编码为“环境表示”，再结合声源与接收坐标回答查询。
在线可以有小隐变量拟合，但神经网络权重不更新的模型与 few-shot 微调模型须分别标注，
不能一边在线训练一边宣称严格的免更新 ICL。

一个值得检验的结构是：
**学习紧凑的环境生成参数，用遵守声源线性关系的读出生成丰富响应。**
有限个环境参数不意味着 source–receiver 输出矩阵低秩。
先测试单个结构改动，不要求同时学习 PDE、做低秩张量和引入后验生成。

这来自已验证的容量线索，不代表神经推断已解决。
已有全局 basis、贝叶斯 prior、posterior-memory 方法已经很强；
旧学习 residual、episodic basis 与 composer 失败要作为设计约束保留。

## 现成数据与限制

- **Deepwave ring**：16 源 × 64 接收器 × 5 个 FFT 频点，有未见系统与形状变化协议。
- **OpenFWI**：5 源 × 70 接收器 × 7 频点，是公开数据补充；只有 5 源，不能声称验证丰富 source 配置。
  当前本机 velocity 与波形不配对，不能作为输入。
- **Ocean multistatic**：9 源 × 48 接收器 × 4 频点；环境只有 3 个变化参数，适合应用示例，
  不足以独自支撑复杂环境泛化。
- **Structural lattice**：8 源 × 32 接收器，可作不同求解器/物理系统的扩展，不自动成为跨域共训结果。

这些现成文件输出的是接收阵列，**不是完整内部波场**。
若要把论文目标改成完整场，必须有对应监督和独立查询真值，不能把阵列图称作 full field。

## 潜在基线与状态

| 基线 | 角色 | 状态 |
|---|---|---|
| source 插值、互易性、最近训练系统 | 简单下限与信息泄漏检查 | 已有实现 |
| response PCA + 各向异性 Gaussian MAP | 强统计先验，不只是 scalar ridge | 已有历史结果，须固定到当前同频协议 |
| posterior-memory / kernel retrieval | 更强的非参数统计对照 | 已有实现；不可从主表省略 |
| 参数/预算匹配 CNP、set attention | 通用学习基线 | 旧 Q3 实现需适配；不自动当作 B 已完成 |
| source-conditioned FNO/DeepONet | 算子学习对照 | 需公平适配相同 prompt，不额外喂真实介质 |
| 已知介质求解器 | 诊断可达精度 | extra-information oracle，不公平主对手 |

历史同频 K=2 的 PCA 类结果已有 Ocean 约 0.0348、Deepwave 约 0.115、OpenFWI 约 0.176；
三域难度和信息量不同，不宜合并平均成一个“通用误差”。
这些是旧结果，不是新学习方法成绩，见[原报告](../../reports/CROSS_DOMAIN_RESPONSE_QUERY_POC_ZH.md)。

## 第一阶段与停止规则

先做 Deepwave/OpenFWI 的同频 held-out-source，复用既有 split 作 DEV，
按同环境、同 prompt、同目标逐系统比较强统计基线与一个学习改动。
在 Ocean 检查应用迁移；不要先叠加远频 extrapolation、连续传感器布局和主动 acquisition。

若神经改动始终无法稳定超过统计先验，保留为科学负结果，
重新检查环境族是否过简单或输入是否不足，不无限扫描容量。
若只靠目标声源互易泄漏、同环境跨 split 或不同测量预算获胜，结果无效。

后续可扩展频率/接收坐标查询，但每次只增加一个轴。
