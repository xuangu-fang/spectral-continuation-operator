# 二维波场四线观测：开发输入已固定，方法成绩尚无

> 2026-10-04。此页记录**输入数据的实现和防泄漏边界**，不报告学习模型成功。数据来自[二维多尺度M0的8个已用开发系统](HELMHOLTZ_MULTISCALE_M0_PILOT_ZH.md)，绝不是新封存测试集。

## 一句话任务

给一个未知二维异质声速环境，在6、10、14三个低频下沿四条固定接收线测到的**复响应**，以及公开的声源、边界/损耗和方程，问同一环境在未测11.3或17频率处的整个复场。前者是带内连续频率，后者是带外查询。主评价仍是完整ROI的raw complex RelL2与能量加权圆相位RMSE，不做全局相位对齐，也不把四线误差当全场指标。

## 本轮实际生成的东西

代码/冻结配置分别见[`prepare_helmholtz_sparse_dev.py`](../src/spectral_continuation/prepare_helmholtz_sparse_dev.py)和[配置](../configs/coherent_helmholtz_multiscale_sparse_dev_20261004.json)。原始257×257真值中，垂直接收线的`x`网格索引为`88,128,168,208`，每线`y=32+3j, j=0,…,64`。每个频率260个复数，三个频率合计**780个复数**；相应三个完整65×65低频场含12,675个复数。接收点是教师网格原生点，不作图像插值。

修正版开发输入在本机：`/mnt/data/xuangu-fang/physics-informed-tensor-learning/datasets/coherent_helmholtz_multiscale_sparse_dev_20261004/`。`dev_00_four_lines.npz`到`dev_07_four_lines.npz`每份**只含**：`samples`，形状`[3,65,4]`、`complex64`；频率向量；归一化`x/y`坐标；`public_spec`里的已知声源位置、宽度、海绵边界和背景损耗。没有目标频率响应、完整低频场、真实声速、纹理系数、包体参数或介质随机种子。单元测试检验准确采点、输出白名单和查询频率不混入输入。运行前已提交冻结实现`c5bd2f1`；本地`manifest.json`逐份记录原真值和公开切片SHA。

**模型侧只能读取上述8份公开NPZ。** 本地manifest和文件生成配置有seed映射，仅供数据维护者复现/评估，不能作模型输入；任何从原始完整真值文件直接加载`spec`、`speed`、查询场或seed的训练/推断脚本都违反这个协议。第一次临时切片包含seed，已改名隔离为`coherent_helmholtz_multiscale_sparse_dev_unsafe_seed_metadata_20261004`，不得使用。这些约束能防止意外API泄漏，不是对恶意读取整仓库合成器的密码学屏障。

## 能说明什么、还不能说明什么

本轮仅把一个物理上更合理的**有限观测**任务切成可复用输入，尚未验证四线是否足够辨识介质，也没有同信息PDE-MAP、统计先验或神经方法分数。完整场经典谱反演在同8环境极准，不能再把它拿来当四线任务的同信息基线；相反均匀背景不使用低频观测，也只能描述异质性造成的难度，不能当强对手。

下一步先在**这8个开发系统**做零/小噪声的四线PDE约束逆解、正则化高维慢度平方与声速先验比较，明确求解收敛和相同标签/在线成本；若经典同信息逆解已接近257网格数值底噪，停止堆学习模块。若有可归因余量，再按[跨方程POC计划](NEXT_CROSS_PHYSICS_POC_ZH.md)另行冻结64验证/64封存并训练最小非线性速度表示。现有8个开发系统不能改名为独立测试。
