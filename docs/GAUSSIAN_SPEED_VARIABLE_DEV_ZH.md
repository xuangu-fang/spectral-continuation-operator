# 第二介质统计族开发：局部Gaussian扰动能否复现声速变量收益？

> 2026-10-04约11:35 UTC，在相关余弦族新16环境确认通过后、**读取本实验结果前**登记。旧Gaussian 8环境已在许多历史实验中使用，是**开发集**，不是新的独立确认。这里只检验原变量机制是否完全依赖余弦合成器；仍用同一个一向波导PDE，不是跨物理域。

## 单一变化与公平信息

训练介质换成旧项目的**3个二维局部Gaussian声速扰动**家族，真隐藏参数为15维但位置/宽度变化形成非线性网格场。直接读取既有512训练系统的64×32慢度平方投影标签与精确系统ID，用相同系统的公开`environment(seed)`在64距离×160深度节点产生**声速网格标签**；两种先验均训练512介质、rank128每环境代码。声速法不接收真实Gaussian参数作为低维坐标，也不使用其解析形状，只有网格标签和公开背景；q-PCA对照读取同批训练标签。两者使用相同60/100/140Hz宽源×65条完整复剖面、已知背景/源/PDE、64＋256段各5次GN、400/800Hz宽/新2m窄源查询。

测试只用反复见过的8个开发环境20261332–339和早已生成的独立教师真值；它们不会被重新称为确认集。q-PCA预置初始化岭1e-9和1e-7都运行，并逐源取较强者；声速初始化岭1e-7来自先前已定设置。主指标是>=50m全ROI未经全局相位校正的complex RelL2，副指标是能量加权圆相位RMSE。报告最差系统、逐系统配对、存储和在线时间，并保留完整逐行结果。

## 停止门槛与解释

800Hz双声源各自声速法平均raw≤0.005、phase≤0.005rad，并相对同源较强q-PCA raw改善≥20%，三项需同时成立。若失败，**不在这8个旧环境上扫描rank、岭、步数、频率或ROI**；照实记录，并把“声速变量收益可能绑定余弦族”提升为主要风险。只有全过，才**另行预登记**全新Gaussian系统确认，不能拿过去使用过的32系统回填正式成功。

即使开发通过，已知精确15参数Gaussian函数族的多初值经典反演在旧8环境800Hz raw约0.00026，拥有额外真生成族信息，仍是结构上限；学习声速PCA不能宣称总体优于它。这条机制检查也不能解决第二个不同波动方程/真实海洋的核心缺口。

## 完整开发结果：相对改善门槛失败，停止本分支

协议/代码提交`092b224`后运行，训练系统与cached q标签首例的真实投影逐元素一致。完整8环境×2频率×2源×3方法共96行结果、逐步优化、时间、训练标签/基SHA在`artifacts/coherent_waveguide_gaussian_speed_variable_dev_20261004/`。声速PCA128在512训练速度网格上解释99.9999816%方差，但这一数字仍不是高频相位保证。

| 800Hz，旧8开发环境系统宏平均 | 宽源raw / phase(rad) | 新2m窄源raw / phase(rad) | 宽/窄最差raw |
|---|---:|---:|---:|
| 学得声速变量＋`c^{-2}`＋同低频GN | **0.003219 / 0.002667** | **0.003435 / 0.002630** | 0.01108 / 0.01000 |
| 同训练系统、同rank128的q-PCA，两预置初始化中较强者 | 0.003415 / 0.002833 | 0.003528 / 0.002702 | 0.00929 / 0.00830 |

预设raw≤0.005和phase≤0.005rad通过；但相对raw仅改善**5.74%/2.64%**，显著低于双源各≥20%门槛，逐系统甚至仅**4/8、4/8**胜出；两个源最差系统的速度法反而更差。速度推断每环境约7.76秒，q约7.38/7.41秒；原始共享基float64数值约1,320,960，q约264,192，尚未对这个Gaussian基做事后深度压缩。**总开发gate失败，按协议停止**：不生成新Gaussian独立确认系统、不在旧8上改rank/岭/步数/ROI继续刷结果。

科学解释须窄：这个相对平滑、仅15连续参数的Gaussian族里，同标签q-PCA本来已有约0.0035高频raw；声速变量的正确非线性映射没有带来余弦族那样的数量级改善。可能是q空间已经足够、数值/优化误差成为主瓶颈，亦可能是速度PCA没有捕捉位置/宽度非线性几何；本实验**不能**单独区分这些解释。但它明确否定“只要从q改到c，在任何波动介质家族都会大幅胜出”的泛化表述。余弦族成功是结构与任务条件相关的正结果，不是通用定理；要写AI方法论文，下一步需换更复杂/不同物理域并给出可预测的结构条件，而不是补救这8个开发样本。
