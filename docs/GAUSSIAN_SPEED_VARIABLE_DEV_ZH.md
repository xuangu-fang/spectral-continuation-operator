# 第二介质统计族开发：局部Gaussian扰动能否复现声速变量收益？

> 2026-10-04约11:35 UTC，在相关余弦族新16环境确认通过后、**读取本实验结果前**登记。旧Gaussian 8环境已在许多历史实验中使用，是**开发集**，不是新的独立确认。这里只检验原变量机制是否完全依赖余弦合成器；仍用同一个一向波导PDE，不是跨物理域。

## 单一变化与公平信息

训练介质换成旧项目的**3个二维局部Gaussian声速扰动**家族，真隐藏参数为15维但位置/宽度变化形成非线性网格场。直接读取既有512训练系统的64×32慢度平方投影标签与精确系统ID，用相同系统的公开`environment(seed)`在64距离×160深度节点产生**声速网格标签**；两种先验均训练512介质、rank128每环境代码。声速法不接收真实Gaussian参数作为低维坐标，也不使用其解析形状，只有网格标签和公开背景；q-PCA对照读取同批训练标签。两者使用相同60/100/140Hz宽源×65条完整复剖面、已知背景/源/PDE、64＋256段各5次GN、400/800Hz宽/新2m窄源查询。

测试只用反复见过的8个开发环境20261332–339和早已生成的独立教师真值；它们不会被重新称为确认集。q-PCA预置初始化岭1e-9和1e-7都运行，并逐源取较强者；声速初始化岭1e-7来自先前已定设置。主指标是>=50m全ROI未经全局相位校正的complex RelL2，副指标是能量加权圆相位RMSE。报告最差系统、逐系统配对、存储和在线时间，并保留完整逐行结果。

## 停止门槛与解释

800Hz双声源各自声速法平均raw≤0.005、phase≤0.005rad，并相对同源较强q-PCA raw改善≥20%，三项需同时成立。若失败，**不在这8个旧环境上扫描rank、岭、步数、频率或ROI**；照实记录，并把“声速变量收益可能绑定余弦族”提升为主要风险。只有全过，才**另行预登记**全新Gaussian系统确认，不能拿过去使用过的32系统回填正式成功。

即使开发通过，已知精确15参数Gaussian函数族的多初值经典反演在旧8环境800Hz raw约0.00026，拥有额外真生成族信息，仍是结构上限；学习声速PCA不能宣称总体优于它。这条机制检查也不能解决第二个不同波动方程/真实海洋的核心缺口。
