# 能回答几个声源，是否等于学到了可复用的传播规律？

> 历史证据 / 技术参考（2026-10-05 归档标记）：保留原实验、数值和复现路径。
> 文内“当前/下一步/待完成”描述属于当时阶段，不是现行任务；请先读[三条 Wave as Prompt 路线](wave_as_prompt/README.md)。

> 2026-10-04运行前协议；原8开发环境的表征能力诊断，不是新神经训练或独立方法测试。

已有Gaussian窄源400Hz结果很准，但它只检验少量照明方向。更基础的问题是：从一个宽源的三个
低频响应识别出的同一代码，能否同时回答一整组没有用于识别的源组合？这比继续选择有利声源更
接近“响应算子”的含义。保持同一理想单向波导，不冒称海洋实测。

## 固定的任务与真值

原60/100/140Hz、65剖面编码完全不变。新的诊断query固定400Hz，输入为前40个满足上下边界的
正交深度模态源。允许它们做任意复系数组合；这是理想相干阵列/算子方向测试，不代表真实设备能
无代价产生任意模态。预测统一64传播模态，不用不足40模态的decoder制造弱基线。

直接teacher用1024距离单元、96模态，输出129个偏移的新距离坐标 `(j+0.37)/129*2000`，每个
存96×40的复传播矩阵。先在另3个数值审计seed20262600–20262602上与2048单元/128模态比较；
将较小模态结果补零后比较完整输出，相对误差必须<0.001才生成原8系统数据。相位约定、源列、
spec、真值收敛、配置和hash一并保存。若失败，保留失败并明确重新设计数值配置，不偷偷裁尾。

## 比较对象与指标

所有方法只使用各自已保存的代码，不对新源响应拟合：

1. 旧16深度项/64段的Gaussian+GN5；
2. 16深度项/256段连续读出+同旧观测5步；
3. 32深度项/256段、相同128维代码+同旧观测5步；
4. 真实介质32项/256段投影，明确为额外信息oracle。

主诊断为各正交源的raw复数相对L2，先在每个系统内平均40源，再在8系统间等权；不做相位对齐。
深度积分用正交模态Parseval等式精确计算，距离ROI仍>=50m。不能把40源当40个独立系统。

另报告传播矩阵的Frobenius相对误差，以及在这40维源子空间内，任意复源组合的最坏相对误差。
后者由误差矩阵与真实响应矩阵的40×40 Gram矩阵的广义特征值直接计算；真实响应Gram若病态，
报告条件数/失效，不通过随意ridge把它变小。它只针对本次频率、接收范围与源子空间，不是任意
频率/任意物理系统的保证，也不取代先前raw主指标。

这项审计不新增现代AI组件；若新表示只在几种声源上有效，就收缩“共同算子”的说法。若对整个
子空间保持准确，它支持进一步研究算子级表征而非逐图拟合，但学习创新仍要另证。

## 已完成：不只对少数Gaussian源有效，但最坏方向更难

三独立数值审计的最坏源组合相对差最大1.514e-5，低于0.001，8份新响应矩阵全部生成。
原8开发环境、400Hz、40个正交源平均如下：

| 冻结表示 | 源平均raw | 每系统内最坏复组合，再系统平均 |
|---|---:|---:|
| 16项/64段 | 0.006941 | 0.015112 |
| 16项/256段 | 0.005488 | 0.011717 |
| 32项/256段，仍128维代码 | **0.001700** | **0.005189** |
| 真实介质32项oracle | 0.000841 | 0.002489 |

新表示不是只对已测试的Gaussian源有效；同维数的较细生成器读出也显著改善整个源子空间。
但平均最坏误差约0.52%，个别系统的最坏方向为1.53%，不能用平均单源0.17%宣传任意请求
都达到0.17%。真实响应Gram的条件数约1，未靠ridge改变最坏方向指标。由于该单向模型近似
无损/一致损耗且这些输入模态可传播，这种良好条件本身也不是一般散射问题的保证。

可复用真值目录为`coherent_waveguide_operator_action_20261004`（完整路径在配置）：8个主NPZ
和3个数值审计NPZ；每个主文件是[129,96,40]复传播矩阵，可按任意40维复源代码组合，不必
再生成单独场。全部是原开发环境的新query，不是11个新的学习样本。`generation.json`含hash，
`convergence.json`含完整数值审计；推断结果在同名artifact审计目录。
