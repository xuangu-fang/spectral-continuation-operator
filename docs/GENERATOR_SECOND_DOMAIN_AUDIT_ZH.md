# 共同生成器：二维异质Helmholtz第二域审计

> 2026-10-03；首先做经典机制诊断，不预先假定第二域需要神经模型。

波导已出现快速共享编码的单域正信号，但其单向传播近似过于特殊。第二域使用本轮已有真正二维
异质Helmholtz teacher（含多向散射、已知吸收层/有限源），检验“从复场识别实算子，再查询新频率”
是否只是波导特例。不同方程不应强行共用同一数值decoder。

输入是6/10/14频率的完整复场，但仅取固定65×65或129×129观测网格，以及已知源、背景和边界损耗。
不输入真实声速/高频目标场。查询7/11/13，由257-grid原teacher提供真值。主ROI仍是两轴[.18,.82]，
源区不删除；原4个开发系统20261132–135先做小诊断，不称新测试。

第一控制根据Helmholtz方程，在观测频率求实慢度平方的联合局部最小二乘。分别使用四阶差分和
正弦谱导数，加入无/一格加权空间平滑控制；真实速度插值为明确的oracle。将估计的实系数连续
读出到257-grid，再由同PDE求解新频率。反演和查询的实际求解成本都报告。

先回答三个问题：观察分辨率是否足够；求导误差是否能由更强经典数值方法解决；生成器本身的
连续系数表示是否准确。如果经典方法已接近oracle，就停止盲加网络。如果有可归因的预测余量，
再用原32训练系统做局部/shared编码诊断，按训练误差决定是否扩数据。不能因波导正结果就直接
启动大规模2D训练，更不能忽略经典谱微分来人为放大AI收益。

这里改变的是已知完整介质的旧协议：完整介质不作为输入，因此旧GMRES数字只作额外信息参考。
但同信息的经典反演/优化仍必须保留。若需要神经模块，训练期介质标签和场标签分别注明。
