# 阶段二假设：学习相位坐标，而不是逐频输出像素

> 历史证据 / 技术参考（2026-10-05 归档标记）：保留原实验、数值和复现路径。
> 文内“当前/下一步/待完成”描述属于当时阶段，不是现行任务；请先读[三条 Wave as Prompt 路线](wave_as_prompt/README.md)。

> 2026-10-03；当前24小时目标的有条件方法分支，不是已成立的论文贡献。

## 为什么从这里切入

已知介质的经典对照中，3个频率的原始场构成的降阶空间误差约0.95；去除介质相关传播相位后，
同样规模的空间配合物理投影达到0.032。学习的候选职责不是重新学会解线性系数，而是让跨频共享的
**连续相位坐标**更适合有限频率范围内的真实波场，从而用更少的基函数维持精度。

这承认[PPRKS](https://arxiv.org/abs/1711.00942)等传统方法的先例。新颖性需来自可泛化的学习表示、
适用范围和误差—成本证据，不能来自给传统降阶换名。

## 明确信息条件

输入：介质声速、源、吸收边界模型，以及同系统的3个完整频率场（6/10/14）。输出：带内未观测频率
的完整复场。目标频率没有场观测。训练/开发按环境分开，32/8系统；目前不是正式封存test。

这一POC提供完整PDE，不属于此前未知环境的稀疏重建。在线阶段仍使用全网格算子作用，不能声称
已经获得独立于高频网格规模的计算成本；连续表示与低成本算子应用需分别验证。

## 最小方法

1. 从已知介质计算背景走时与直线介质走时。后者是沿源到点的直线路径积分声速倒数。
2. 小型共享网络读取查询点附近的介质和路径特征，修正两种走时的差；同一走时用于全部频率。
3. 各已知场除去该频率的传播相位，得到包络；在查询频率乘回相位，组成少量基函数。
4. 在基函数空间内解最小残差问题，确定复系数，生成完整场。网络只学习相位坐标，不直接输出像素值。
5. 唯一训练目标为开发协议中训练系统的原始复场相对平方误差；不堆叠相位、幅值、PDE等损失。

简记为：

$$
\tau_\psi(x)=\tau_0(x)+\alpha_\psi(x,c,s)\,[\tau_{ray}(x)-\tau_0(x)]
$$

$$
v_j(x,f)=u(x,f_j)\exp\{2\pi i(f-f_j)\tau_\psi(x)\},\qquad
\hat u(x,f)=\sum_j a_j(f)v_j(x,f).
$$

系数通过已知离散波动方程的最小残差解得到，目标场仅参与训练损失/验证，不进入推理。
该参数化先限制在单传播相位，不能提前宣称覆盖强多路径、阴影区或焦散。

## 控制与停止条件

- 固定背景走时、固定直线走时、经典首达走时：分清“已有物理先验”和“学习增量”。
- 只训练一个全局走时混合系数：排除神经网络只是做全局调参。
- 神经相位坐标：只有未见环境优于以上对照，才进入多seed/独立频率验证。
- 用目标真值拟合基空间系数，仅作为容量oracle，绝不算可部署性能。
- 第一门槛：原始复场误差低于0.03，并比最强同信息经典对照降低至少20%。若失败，先查看训练误差、
  基空间oracle与物理读出误差，不扫网络宽度/深度。
- 不会把该分支的成功或失败外推成“所有波场都需要/不需要学习”。Ocean仍保留模态分支证据，后续
  是否能统一取决于实证，不强行用同一个公式覆盖两个域。

## 第一轮反馈与有条件的第二轮

8个开发验证环境：直线介质相位0.033352、首达走时0.033425、全局学习系数0.033351；神经相位模型
最优checkpoint仍是第0步，未优于初始化。1409参数、1800步的本次训练未支持相位修正的增量，不能
解释成所有可学习相位都无效。首达走时由scikit-fmm计算，并校正有限源半径的均匀介质偏差；其单元
测试在均匀介质下恢复解析走时。

随后只改包络容量：四环境中，原6列基空间0.03243，加入两列源相关函数0.02567；每个载波乘三个
固定径向包络、共18列，为0.02302；再加源函数为0.02253。目标真值最佳拟合分别约0.02282、0.01995、
0.01709、0.01679。这提示不应把全部资源继续放在相位坐标上。

第二轮保持相位不动，学习两个平滑包络因子，匹配18列固定径向基；另设仅学习两个全局径向指数的
控制。读出仍是物理最小残差，仍只有复场监督损失。此轮特征/网络/复线性代数采用双精度，避免对平滑
函数作二阶差分时把浮点量化误差当成物理误差。结果：固定径向0.023793、两个全局指数0.023790、
神经包络0.023080，约3%改善，仍未通过20%门槛。相位网络的双精度复跑也没有改变负结论。

按源附近误差进一步补的经典对照：以真实Gaussian源的均匀介质复Green响应为参考因子，再加介质
传播相位，在4个环境上仅6列达到0.023159，接近18列径向基的0.023018。不能将参考物理遗漏造成的
误差当作神经网络容量瓶颈。该分支当前是机制审计，不是已成功的新AI方法。

## 新颖性边界：本轮补查的相关方向

以下为原始论文/官方页面核查；尚未复现它们的完整实验，不把摘要性能当作我们数据上的比较结果。

| 已有工作 | 已占据的核心思想 | 对本项目的约束 |
|---|---|---|
| [PPRKS，2017/2018](https://arxiv.org/abs/1711.00942) | 去除快速传播相位，压缩频率相关降阶空间 | 相位预处理本身不新 |
| [Galerkin POD-NN，2024](https://arxiv.org/abs/2406.13567) | 用神经网络预测波动方程降阶系数，含3D Helmholtz/Maxwell | “神经网络+低秩系数”不是独立创新 |
| [McMg，2026预印本](https://arxiv.org/abs/2606.30495) | 粗空间保留多通道局部相位/方向信息，介质条件化的可学习Helmholtz预条件器 | 波相空间/多通道学习已有人深入做；不直接宣称首创 |
| [NGO架构分析，2026预印本v3](https://arxiv.org/abs/2605.19867v3) | 输入投影与输出基一致、源线性对Galerkin类校正的重要性 | 编码/读出需要算子结构，不能只凭网络名称 |
| [Gaussian Particle Operator，ICML 2026](https://proceedings.mlr.press/v306/li26aq.html) | 可学习几何基与基空间间算子，区分表示和预测，支持非规则与3D数据 | 学习几何基并不自动构成波特有贡献 |

由此得到的是研究要求，不是已成立的新颖性声明：若继续，应证明某个**保留复杂相干性的连续表示**
在跨频预测、独立坐标和复杂介质上具有现有基空间缺少的精度—复杂度优势。不能将新论文缩成已有
预条件器的较弱版本，也不能只靠“这次用了MLP”满足AI贡献。
