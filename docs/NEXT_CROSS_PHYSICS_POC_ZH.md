# 下一阶段：让“物理变量中的可学习表示”接受真正的跨方程检验

> 2026-10-04阶段交付后的**研究设计**，不是已完成实验或已冻结的新确认协议。先读[阶段决策](PHASE_REPRESENTATION_DECISION_20261004_ZH.md)、[报告第21–22节](../reports/COHERENT_CONTINUOUS_REPRESENTATION_PROGRESS_ZH.md)和[真介质投影归因](VARIABLE_PROJECTION_ATTRIBUTION_ZH.md)。当前跨两物理域的论文gate**没有**通过。

## 为什么不能拿现有二维Helmholtz结果“补齐第二域”

旧二维异质Helmholtz的完整复场、已知源/边界、65×65观测网格里，经典正弦谱微分反演再求解新频率的raw已约**9.9e-5**，129×129约7.7e-5；真正257→513数值teacher差约0.001–0.002。给这种信息条件再放一个声速PCA/autoencoder，即使成绩相近也难以构成AI增量；拿弱四阶差分0.018作为唯一对照会误导。原环境又只有4个轴对齐Gaussian扰动，速度理论分离rank≤4，天然偏向经典低秩。详见[第二域旧审计](GENERATOR_SECOND_DOMAIN_AUDIT_ZH.md)。不能把波导两种介质**统计族**当作两个物理方程，也不能用旧完整场Helmholtz的“表示可压缩”代替新方法验证。

## 更科学的问题，不是人为制造难度

真正值得问的是：在**源和波动方程已知，但新环境的介质/边界只通过有限复响应暴露**时，哪个物理变量和哪种学得的环境坐标能让少量低频信息识别出对新频率/新源**相位保真**的共同传播机制？接收阵列/少量剖面比全二维连续场更接近海洋和实验；它也自然让“环境表示＋查询作用”而不是像素补全成为问题核心。但减少观测并不自动制造学习必要性，必须与**同信息的PDE约束反演、恰当先验和足够迭代**比较。

建议下一轮以**真正二维、含回散射的异质Helmholtz**作验证域，以**非余弦的随机多尺度介质**取代四Gaussian，以海洋的**距离相关声速剖面**作为旗舰后续域。两个域不强迫共用数值求解器，只共享“学环境生成变量/坐标，物理或学得作用回答复场query”的建模原则。不要先上flow或主动选点；先问同等信息与预算的表征是否有可识别、可预测优势。

## 分阶段最小POC与停止门槛

| 阶段 | 最少要固定/完成什么 | 继续条件与失败解释 |
|---|---|---|
| M0 数据与数值 | 训练介质≥512、验证≥64、新系统封存测试≥64；随机多尺度二维速度，不把真实合成参数交给模型；4个固定接收线×每线65点×3低频作主输入，额外2/8线作预算曲线；新频率、新源、连续细坐标真值；至少4个新系统做257/513网格收敛，预设真值误差<0.005。 | 如果教师收敛失败，先修求解器；不拿离散误差当方法差。若4线不足以区分环境，输出不确定性或调整任务声明，而不是偷偷加入真实介质。 |
| M1 表示与信息 | 同训练介质标签、同每环境代码及共享存储下，比速度空间、慢度平方空间、响应敏感低秩/非线性速度坐标。分列测试真介质**欧氏投影oracle**、低频部署、可选目标响应oracle；所有真介质/目标读取均明确标注。 | 若两种投影已接近或经典同信息反演已接近数值底噪，停止容量堆叠；不会通过弱化基线找“学习优势”。若速度投影好但低频部署差，问题转向辨识与稳定性；若投影已差，才升级表示。 |
| M2 最小learning增量 | 首选一个共享、连续且物理变量明确的**非线性速度图/函数张量解码器**，让网络只学环境坐标或局部相干作用；已知PDE负责复相位组合。与同输入、同训练标签、同在线时间/内存的PCA＋物理GN、PDE约束MAP/多初值、恰当TV/随机场先验以及完整场经典谱逆上限分别比较。 | 只在**真正第二PDE、未见系统**上同时做到raw complex RelL2≤0.10（优先≤0.05）、phase RMSE≤0.15rad、相对最强**同信息同预算**物理/统计基线≥20%稳定改善，才考虑顶会主方法；无收益就报告可辨识或基线已经强的边界。 |
| M3 Ocean旗舰 | 使用**距离相关**声速与已知源/边界条件，分别验证真实/仿真数据中的相位、噪声、少量接收阵列；温跃层/海底等公开与隐藏信息写清楚。 | 均匀水层的解析传播基线很强，不能再用它证明学习必要性；Ocean的应用有效性和二维Helmholtz的跨方程方法增量均需单列，不能互借成绩。 |

量化门槛是**下一阶段的建议**，不是现有结果；实际数据/源/接收器位置/数值审计和强基线必须在新真值或封存集打开前另建运行前协议。别复用旧余弦新16、Gaussian旧8或旧Helmholtz4来做下一候选的正式泛化确认。能投什么论文取决于M1/M2是否真过，而非把现有PCA与oracle换个名字。
