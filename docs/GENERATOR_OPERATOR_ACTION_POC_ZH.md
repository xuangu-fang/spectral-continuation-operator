# 单次响应准确，是否等于共同算子准确？

> 2026-10-03；有条件的单机制实验，不是已经证实的方法贡献。

目前实生成器能读出连续频率/空间，新声源高频的误差仍被放大。原声源的场loss只检验算子在一个
激发方向上的作用；低损失未必约束其他声源会用到的方向。这是一般线性系统的区别，不是新的定理。
我们想检验：共享编码器是否能借训练环境的更多激发方向，学出更可复用的传播表示。

保持512训练环境、原3个宽源观测、网络/latent/物理decoder、优化步数和主指标不变。仅改变训练
输出请求：原Gaussian源，或每步随机深度10–90m/宽度2–10m的Gaussian源。频率仍限于原70/80/90/
110/120/130Hz。推断编码器仍看原宽源context，不提供新源场。

为了不额外生成完整原始数据，使用训练期已有真实介质投影系数，经相同64单元可微decoder合成
请求响应。故必须同时做“投影teacher + 原声源”对照，隔离此前256单元真实场teacher的改变。
这是更多地使用训练介质监督；不是纯观测自监督，更不是在开发介质或400Hz真值上训练。

两个模型均从相同系数预训练checkpoint开始，3000步、batch8、单一raw复场相对平方误差；不叠加
幅值/相位/PDE/系数loss。checkpoint只按原8开发环境和原声源六个带内query选，不按窄源/400Hz选。
先做seed42机制控制：若新请求相对最强匹配参照改善不足20%，或原query退化超过10%，不直接扩
三seed或继续调容量。所有旧控制，包括经典充分迭代与Gaussian prior，都保留。

正结果也不等于物理结构是新的。潜在贡献应是**对未观测请求可复用的学习表示**及其误差/成本证据，
不是把随机源训练改名成foundation model。负结果则说明当前瓶颈未被“响应覆盖”这一机制解决。
