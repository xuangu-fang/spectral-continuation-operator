# 编码器是否丢掉了全程相位信息？

> 单机制开发实验；不接触64新系统来选型。既有独立审计继续使用原冻结模型。

共同生成器已经有足够的容量；线性介质先验oracle也很准。问题更可能在推断端。当前网络输入
把三个观测频率压缩为每个距离单元的正规方程，它对全程传播的一致性并不充分。这里检验是否
应保留可观测的“coherent innovation”：当前模型与实测复场的差，包含相位也包含幅值。

## 唯一变化

保持同一1024实系数表示、同一48宽FNO、同一物理解码器、同一512训练/8开发环境。
先用已有局部物理初值传播三个**已观测频率**，与实际观测作复数相减。在已知背景模态中移去快速
传播相位，但不反向放大衰减分量；用已知初始源的尺度和共同相位归一化。相邻端点平均到64单元，
保留32模态×3频率×实虚两部分的192通道。没有读入目标频率或真实开发介质。

从已经完成的seed42复场模型初始化；输入层新增权重严格为零，因此第0步必须复现旧模型输出。
固定继续3000步，单一raw复场loss；不加PDE/相位/标签多项loss，不改主指标。

匹配控制把192新通道置零，其余参数数目、初始化、训练步数、batch抽样与优化器全部相同。
保留原强经典/核基线，并给核回归同一新输入、同一9项既定bandwidth/ridge选择机会。
新增三频率物理传播的编码成本必须记录，不能声称“只多了一层输入而无成本”。

## 判断和停止

- 首先验证全局相位/尺度规范不改变新特征、零残差为零、训练初始化一致。
- 若相对匹配续训控制与最强核未改善至少15%，不扩三seed或扫描输入变体/网络宽度。
- 即使通过，也只算开发机制信号，正式20%门槛与第二域要求不变；不能重新使用原64系统来调模型。
- 此实验是物理残差驱动的摊销推断，思想已有先例，不自动构成新颖性。

若失败，说明“多保留这类相位残差”在当前学习协议下没有用；不是所有观测编码或波动表征都不可能。
