# 先检查小隐空间中的全程物理校正

> 原8开发环境的新经典控制；不更改64新环境审计的冻结主比较。

前面的局部Gauss–Newton只匹配局部导数，128维先验内L-BFGS则可能受优化条件影响。二者都没有
排除“全程传播的精确灵敏度 + 小规模线性求解”这一强基线。128维先验本身的表示oracle已很准，
因此先做这个控制，再决定有没有必要让网络学习校正算子。

每段的传播矩阵是平方根生成器的指数。通过矩阵函数的解析Fréchet导数，将每段的变化沿完整传播
路径传下去，得到128个先验方向对三个观测场的Jacobian。它不对观察数据求空间导数，也不丢弃
距离变化项。传播/衰减模态都要通过有限差分检查；遇精确截止奇点不得偷偷截断导数。

从已有Gaussian先验估计或冻结神经估计开始，仅在训练512介质拟合的128维方向内修正。固定
0/1/2/5步，ridge为正规矩阵平均对角的1e-8；最大系数步长0.01、context-only回溯
1/0.5/0.25/0.125/0.0625。全部结果保留，不看query truth决定停止或取步长。
单一context相对复场平方误差；它是经典Gauss–Newton，不是新AI模块。

只记录校正与六query成本，前面的初始编码另计；不是公平端到端加速结论。如果已非常快且准，
就停止在该小维度上训练“现代”预条件器；若仍有明确的计算瓶颈，才有学习近似的依据。

## 已完成：强基线推翻旧方法优势

Gaussian初值0.009872，1/2/5步 **0.000734/0.000703/0.000702**。一次校正平均约0.336秒，
只计校正，共享机器，未含编码/query/离线PCA；不当作正式总延迟。原神经初值的受限校正反而
停在约0.0059；先将它投影回训练先验空间，再校正5步可到0.000709，说明子空间外误差是重要混杂。

0.00558，原神经0.03616，原自由1024系数L-BFGS2000步0.02114。所有4频率、32/64模态结果
保留，不能按query挑选2步后冒称在线停止策略。

结论是训练数据形成的物理先验 + 适配它的精确推断很强，而不是“不需要任何学习”。当前没有理由
