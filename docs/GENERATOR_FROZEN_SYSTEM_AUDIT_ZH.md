# 共同生成器：冻结后的独立系统审计

> 2026-10-03；不是“已经通过方法gate”的确认，而是防止反复使用8个开发环境导致乐观归因。

## 冻结对象

原512训练环境和8开发环境不变。冻结三seed系数预训练/复场微调模型、输入归一化、三context65剖面
协议、64距离单元×16深度系数表示、核与Gaussian prior的原开发超参数。所有神经checkpoint、基线
配置和当前代码哈希在**生成新系统前**保存到新数据目录的`freeze_manifest.json`。不再用新系统选型。
旧Ocean封存集继续不打开。本审计是新建的单向波导IID系统集，不是第二域，也不是真实海洋验证。

## 新系统与请求

64个预定独立seed：20262300–20262363，与训练/开发/数值审计seed无交叉，分布不变，不挑困难或有利
样本。原宽源60/100/140Hz作为context，目标70/80/90/110/120/130Hz零观测；另一份直接真值覆盖
同环境2m窄源140/200/300/400Hz和新的连续坐标，编码器不能读后者的任何场。

原请求由1024距离单元/32模态直接求解，2049×129坐标，与原编码协议一致；窄源请求1024单元/
64模态、2049×385新坐标。先在额外20262400/1/2上比较2048单元、48/96模态；最大raw差须≤0.001。
存全部环境spec以复现teacher，但推断仍只可用已知静态背景/源/边界；真实扰动仅作明确oracle。

## 固定比较与验收

- 不校正：正则经典、核、Gaussian prior、三seed神经；
- 相同context-only物理校正5/20步：上述各初始化公平比较，不能只给神经加校正；
- 经典充分迭代作为精度参考，必要时固定500步，不以新query结果停早/选步；
- 原请求raw complex RelL2为主指标，按系统等权；另报相位RMSE、尾部误差和窄源高频各频率曲线；
- 三seed先对每系统平均，再用系统配对bootstrap报告相对最佳固定经典/统计参照的区间；同时保留
  每seed结果，不把seed×频率当独立环境；
- 编码/校正/读出成本与离线训练成本分开。新系统成本只是共享机器pilot，不补造独占速度证明。

若新系统优势不稳，原8开发结果不能继续作为主要泛化证据。即使全部单域通过，也不填补第二域
学习优势的缺口。原两域raw/phase与20%方法gate不降低；本独立审计允许清楚的负结论。

结果公布后这些系统不再用于本候选调参；若据此设计新方法，必须另划新的最终测试系统。
