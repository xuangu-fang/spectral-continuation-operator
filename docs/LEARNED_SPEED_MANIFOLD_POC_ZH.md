# 最小方法POC：从“慢度平方PCA”到“学得声速基＋精确非线性物理映射”

> 2026-10-04约10:35 UTC，在taper10原固定先验、重拟合PCA256均未到0.05，而额外知道真余弦速度族的经典非线性反演仅约0.004后登记。首轮只用已看过的taper10新16系统作**开发/机制筛选**；不重新命名独立测试。只有以下开发gate通过，才按另一个运行前协议生成此前不存在的taper7.5新系统。当前仍是**同一一向波导PDE**，不是第二物理域。

## 为什么这是一项而不是组件堆叠

原PCA先验直接在线性慢度平方系数`q`上学习子空间，256维尽管解释taper10训练标签99.99675%方差，真介质欧氏投影的800Hz响应仍约0.067。精确函数族逆解在255个**声速**坐标上先构造声速，再经已知非线性`c^{-2}`成为传播生成器，仅用相同低频响应便达到约0.004。这里最小地拆除“知道真余弦基”的额外结构：不手写余弦方向，只从1024份训练介质标签学一个255维声速空间；但保留**物理上正确的非线性声速→慢度**和相同传播/相位读出。这样可以直接检验：之前的差距究竟主要来自**表示在哪个物理变量上**，还是来自知道精确合成器函数族。

## 固定开发协议

- 训练介质标签：原taper5的512系统seed20264000–4511，已有taper10的512系统seed20266000–66511，均与16个开发seed20267000–015分离。两族RMS15m/s、16×16余弦合成，但**速度基训练只读介质网格，不接收真余弦系数或taper标签作为显式模型结构**；公开背景温跃层在形成速度扰动前扣除。q-PCA强对照使用**同1024个介质样本**在64段×32深度项的投影标签。
- 两种方法每环境代码都为255实数，64段/160积分节点的训练声速PCA共享基与64段×32深度项q-PCA共享基的**存储成本分别记录**；全局基大小不被叫作255参数。速度方法把连续插值的声速`c(z,r)`经已知`(c_ref/c)^2`变换投影到32深度项，其解析Jacobian进相同64段+256段各5步GN，再以128传播模态查询400/800Hz宽/新2m窄源。无需目标频率观测或测试介质标签。
- 输入同60/100/140Hz宽源×65完整深度剖面、已知源/背景/一向方程。速度方法的线性初始化岭1e-7来自先前精确族基线，q-PCA对照取事前指定1e-9与1e-7两条中**效果较好的那条**，不再在开发结果上扫描别的岭/秩/步数。其余GN阻尼、最大系数步长、线搜索、完整>=50m ROI和raw complex RelL2/能量加权圆相位RMSE相同。
- 首轮预设开发gate：800Hz双源各自速度方法系统平均raw≤0.05、phase≤0.05rad，并相对**同样训练样本与255代码下、两条初始岭中更强q-PCA**的对应raw各改善≥30%。400Hz、最差系统、低频残差、真实介质投影oracle和成本一并报告。任一门槛失败，保留负结果、停止在这16个系统上调该方法；不得降低门槛或挑频率。
- 只有全部开发gate通过，才另生成taper7.5全新系统与高精度目标，固定模型/超参数做条件性确认。新分布在训练的taper5与10之间，是**插值型统计迁移**，不是外推到任意介质、更不是新波动方程；即使确认通过，也只是学习物理变量选择的一个POC，尚不能形成顶会主论文。
