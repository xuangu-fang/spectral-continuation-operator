# 介质相关尺度变化：固定表示的额外分布外压力测试

> 2026-10-04 09:24 UTC 开始准备；本页、配置及实现须在生成任何新目标真值前提交。它发生在主要同分布32系统结果及精确已知生成族基线都已被看过之后，是**后续固定方法的探索**，不追认成原论文主实验的预注册测试。

## 为什么做

目前rank256统计介质先验能在同一相关谱随机族的新32环境，把800Hz未观测复场raw降到约0.015。但这个族的训练和测试随机谱都有相同的频谱衰减尺度5。若只改变介质空间相关尺度，模型仍能查询吗？这比再在同一族增加系统更直接地检验“学到的是通用相干传播表示，还是非常依赖训练介质统计”。

## 冻结协议

- 方程仍是**同一个一向声学波导**，不是第二物理域；背景温跃层、边界和源仍公开。训练512系统的余弦谱介质、rank256 PCA先验和64段+256段各5次GN全部复用，不再拟合、更不改网络。无目标频率观测。
- 新16系统seed20267000–20267015，审计seed20267100–101，与训练、开发和同分布确认全部分离。介质仍为16×16余弦速度场，DC系数固定0，速度扰动RMS15m/s；仅把随机系数的高频衰减尺度从训练的5增至**10**。同seed的背景、源和标准正态随机数可配对，但本实验不把新系统与旧新32误称逐系统配对。
- 输入仍为60/100/140Hz宽源×65个完整深度剖面；目标400/800Hz宽源和新2m窄源，4097×513连续采样网格，完整>=50m ROI不配准raw complex相对L2为主；能量加权圆相位RMSE分报。1024段/160模态/384积分点数值真值，2048/192/512独立审计，误差须<0.001。
- 额外报告两种**读取真实测试介质的非部署oracle**：真介质在训练rank256 PCA子空间的欧氏投影，以及256段32深度项的真实介质投影。前者不是真正的响应误差下界；它们只帮助区分表示容量和低频推断。不得与部署方法混排排名。
- 探索门槛在800Hz双源各自检查：rank256部署均值raw≤0.10、相位≤0.10rad、至少12/16系统raw≤0.10；并通过上述数值审计。400Hz和所有失败系统一并报告，不删异常。通过仅说明这个**有限相关尺度变化**未破坏方法；失败则根据oracle与context误差归因，不能说波场信息论上不可预测。

## 完成结果：原固定表示明显不能跨这个相关尺度

16个新系统、400/800Hz双源共192行部署/两种oracle评价全部完成，32份新目标NPZ保存于上述数据目录。2个独立审计系统×2频率的teacher与更细求解差最大**0.0002393**，数值门槛通过。部署rank256的结果是：

| 同一PDE，训练谱尺度5→测试尺度10 | 400Hz宽源 raw / 相位rad | 400Hz窄源 raw / 相位rad | 800Hz宽源 raw / 相位rad | 800Hz窄源 raw / 相位rad |
|---|---:|---:|---:|---:|
| rank256低频context推断 | 0.1810 / 0.1406 | 0.1952 / 0.1529 | **0.4155 / 0.3743** | **0.4350 / 0.4041** |
| rank256真实介质欧氏投影oracle | 0.1300 / 0.0988 | 0.1194 / 0.0895 | 0.2925 / 0.2402 | 0.2789 / 0.2300 |
| 真介质32深度项oracle | 0.00152 / 0.00125 | 0.00148 / 0.00118 | 0.00285 / 0.00238 | 0.00281 / 0.00232 |

800Hz部署宽/窄源最差单环境raw0.6553/0.7719，**两源均0/16个系统达到raw≤0.10**；预设均值raw≤0.10、相位≤0.10、至少12/16系统达标三项全部失败，只有数值审计通过。这个大幅负结果不能用teacher数值误差解释，也不是目标频率观测混入低频拟合。

归因应严格限界：真介质32项oracle约0.003说明当前物理读出/32垂向项足以承载此族；真介质在**训练谱尺度5的PCA256空间作欧氏投影**仍约0.29，说明当前训练统计子空间与欧氏投影准则**不足以保住**这一转移下的高频响应。但欧氏投影不是最优响应代码，不能据此证明整个256维空间绝不可能拟合目标。部署raw还高于这一额外信息投影，提示低频估计/先验适配也增加误差，但两项误差不能简单线性相减。为确认子空间与投影目标的区别，另有明确读取目标800Hz宽源的[事后响应优化oracle协议](SPECTRAL_TAPER_RESPONSE_ORACLE_ZH.md)；它不改变本节负gate，也不是可部署方法。

另一个直接读出的诊断是：部署5+5步结束时，低频context的归一化平方残差在这16个新环境平均约**2.93×10⁻⁵**，而同分布新32环境的rank256约**4.66×10⁻⁸**；前者约高630倍，且最终fine步16/16都接受非零线搜索步长，并非简单的“最后一步全部卡住”。这表明训练子空间对新细尺度介质连低频context也拟合得明显较差；但由于两批环境不同，不能把这个比例当成严格的配对因果估计。

与先前同分布新32环境800Hz raw0.01475/0.01532相比，当前0.416/0.435的差距很大，但**两批并非同seed配对**，且taper改变了介质细尺度，不能把这个比例解释成严格因果效应估计。更不能把同一个一向方程下的新统计族叫作“第二物理域”。这条负结果对论文定位很重要：现有近完整PCA+物理解码器并没有展示令人信服的介质统计泛化；若想讲通用波场表征，下一步必须正面处理训练先验外的相位信息，而不是只加深当前同族网络。
