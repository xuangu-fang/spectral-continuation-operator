## 按研究阶段追溯

| 历史阶段 | 保留的主要价值 | 后续默认状态 |
|---|---|---|
| APEX/APEX-H 低→高频 | 幅相迁移的条件性动机与失败边界 | 不重启整数倍/效率 gate 扫描 |
| 连续谱 pole/ODE | 模型容量与外推失效诊断 | 不把模型失败说成物理不可预测 |
| 稀疏谱校准、多保真 | 真配对信息、独立 LF/HF 失败 | C 可借鉴，但要新定义模型偏差 |
| horizon 与主动查询 | 风险判断与动作收益不同 | 暂停，先解决重构/预测 |
| 通用 token / 多分支表征 | 表示信号、跨域数据、固定特征负结果 | 不再开放式扩张表征任务 |
| Response query / PFTO / PBNO | B 的数据、强统计基线和 learning 负结果 | 复用组件；缩回简单同频新源任务 |
| 连续相干 / 物理生成表示 | 表示变量机制、强 PDE 对照、数值与可辨识性区分 | 为 A/B/C 提供假设，不以诊断替代方法 |
