# 分布外PCA256代码的双声源共同响应oracle：最后一个有界诊断

> 2026-10-04约09:55 UTC，在原相关尺度OOD失败、又看过单目标宽源响应oracle后登记。**完全事后、目标频率真值泄漏、真实介质初始化**；不是新测试、不是可部署方法，不修改任何原OOD门槛。完成此诊断后不继续对同一批系统调rank、步数或oracle目标。

单目标宽源oracle把800Hz宽源raw从真介质欧氏PCA投影的0.2925降到0.0754，但新窄源只从0.2789降到0.2232。这个现象可能表示同一256维代码倾向于补偿某一声源响应；但“未见源误差仍高”也可能只是因为它**没有参与oracle目标**。为了区分这两种解释，本最后一步把800Hz宽/窄两源在257个完整深度剖面的**目标真值都交给**同一rank256代码，并共同做固定5步GN；初值、64拟合模态、256传播段、岭、线搜索、步长与单源oracle相同，全部16系统评价原4097×513完整ROI。

如果双源都降到≤0.05，说明这个固定空间可以在知道目标场时承载两源响应，旧欧氏投影和低频推断才是主要障碍；如果双源仍高，只能说当前**有限步局部适配**未找到高保真共同代码，不能给出全局容量不可能定理。无论结果如何，均不得写成低频预测成功、zero-shot新源或学习方法胜利；两个源都泄漏目标数据。结果保留每步指标与全部系统，不筛最优步，也不再由此启动另一个相同问题的oracle搜索。
