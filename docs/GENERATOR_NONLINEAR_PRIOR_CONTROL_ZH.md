# 先验只用作初值，还是约束整个反演过程？

> 历史证据 / 技术参考（2026-10-05 归档标记）：保留原实验、数值和复现路径。
> 文内“当前/下一步/待完成”描述属于当时阶段，不是现行任务；请先读[三条 Wave as Prompt 路线](wave_as_prompt/README.md)。

> 在原8个开发环境上的补充经典控制；不是新神经模块，不使用64冻结新系统的结果选型。

上一对照先从Gaussian介质先验得到一个估计，再允许1024个实系数自由调整。它不能替代更完整的
先验反演：假如观测对某些方向约束弱，自由优化可能离开训练介质所在的合理低维区域。

本控制使用原先已选的128维实生成器PCA基；每步只调整这128个白化系数，由同一个解析decoder
匹配三个观测频率的场。128维基完全由512训练介质拟合，不用开发介质真值。
固定三种Gaussian正则强度0/1e-8/1e-6，固定5/20/100步，全部查询结果保留；不按query误差提前停止。
0正则仍有低维子空间限制，不等于原1024维自由优化。它是标准统计先验与非线性物理似然的组合，
不是AI创新，也不声明概率校准。

另报告开发真实介质投影到这个训练基的响应误差，明确作为容量oracle。它不参与初始化/优化。
只有发现这个线性先验的表示本身显著限制精度，才值得启动更复杂的可学习非线性生成器流形；不能
因为Gaussian听起来不够现代，就忽略其完整推断形式。

64新系统的原主比较仍保持冻结；若此补充基线更强，将如实削弱原方法主张。任何新独立验证都需
另标记为补充协议，不能回写成数据生成前已经预先约定的主实验。

## 已完成结果

128维先验对真实介质的投影oracle为 **0.000810**，与1024维真介质表示的0.000782很接近。
所以当前没有证据支持“必须学习更复杂的非线性介质流形”。
先验内非线性反演20步约0.007668、100步0.00584–0.00587；三个预定正则量级结果相近，
没有胜过Gaussian初值后自由调整1024系数的同20步0.004153。潜在原因包括白化参数的优化条件，
不能把该优化结果解释成线性先验容量不足，也不因此继续扫秩/正则/架构。
此处8实例联合优化与逐实例成本表分开；不使用时间数值宣布加速。
